# ذهب برو 730 — نسخة PWA السحابية

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق (للمحل) |
| `portal.html` | صفحة الزبون (يرى حسابه فقط) |
| `cloud.js` | الدخول والمزامنة مع Firebase |
| `firebase-config.js` | **إعدادات مشروعك — تملؤها أنت** |
| `database.rules.json` | قواعد الأمان — **تنشرها في Firebase** |
| `sw.js` · `manifest.json` · `portal.webmanifest` · `icon-*.png` | تثبيت التطبيق على الهاتف وعمله دون اتصال |
| `firebase.json` | إعداد النشر على Firebase Hosting |

## الإعداد (مرة واحدة)

### 1) أنشئ مشروعاً جديداً
1. افتح https://console.firebase.google.com ← **Add project** ← اسم مثل `goldpro730` ← عطّل Google Analytics ← Create.

### 2) فعّل تسجيل الدخول
2. **Build ← Authentication ← Get started ← Sign-in method ← Email/Password ← Enable ← Save.**

### 3) أنشئ قاعدة البيانات
3. **Build ← Realtime Database ← Create Database** ← الموقع **europe-west1** ← **Start in locked mode** ← Enable.
4. انسخ رابط القاعدة (يبدأ بـ `https://` وينتهي بـ `firebasedatabase.app`).

### 4) انشر قواعد الأمان (مهم جداً)
5. في Realtime Database ← تبويب **Rules** ← امسح كل شيء والصق **محتوى `database.rules.json`** ← **Publish**.

### 5) إعدادات التطبيق
6. **Project settings (أيقونة الترس) ← General ← Your apps ← أيقونة الويب `</>`** ← سمّه ← Register app.
7. انسخ القيم (apiKey, authDomain, databaseURL, projectId, appId) والصقها في **`firebase-config.js`** مكان `YOUR_...`.

### 6) انشر الملفات على الإنترنت (اختر واحدة)
**أ) Firebase Hosting (الأسهل):**
```
npm i -g firebase-tools
firebase login
firebase use --add        # اختر مشروعك
firebase deploy
```
**ب) GitHub Pages:** ارفع كل الملفات إلى مستودع وفعّل Pages، ثم في Firebase: **Authentication ← Settings ← Authorized domains ← Add domain** وأضف `اسمك.github.io`.

### 7) أول تشغيل
- افتح الرابط ← **إنشاء حساب جديد** (بريدك + كلمة سر).
- لنقل بياناتك من نسخة ويندوز: في ويندوز **الإعدادات ← تصدير نسخة**، وفي النسخة السحابية **الإعدادات ← استيراد نسخة**.
- على الهاتف: قائمة Chrome ← **إضافة إلى الشاشة الرئيسية**.

## إعطاء الزبون حسابه
1. افتح الزبون ← **بوابة الزبون**.
2. اكتب اسم محلّك، واسم مستخدم (إنجليزي)، وكلمة سر ← **إنشاء حساب الزبون**.
3. أرسل للزبون: **رابط `portal.html`** + رقم هاتفه + كلمة السر.
4. كل ما تُدخله عن الزبون يظهر له تلقائياً. **إلغاء وصول الزبون** يمسح ما يراه فوراً.

## كيف تُعزَل البيانات
- بيانات المحل في العقدة `shops/{uid المحل}` — لا يقرؤها إلا صاحبها.
- كل زبون له عقدة خاصة `portal/{uid الزبون}` فيها ملخص حسابه فقط — لا يقرؤها إلا هو، ولا يستطيع تعديلها.
- الزبون لا يقرأ عقدة المحل ولا عقدة أي زبون آخر.

## حدود معروفة
- **الصور (الكاميرا بالـQR)** تعمل مع نسخة ويندوز فقط حالياً.
- **تغيير كلمة سر الزبون:** ألغِ وصوله ثم أنشئ له حساباً جديداً باسم مستخدم جديد.
- **رقم الهاتف فريد على مستوى كل المحلات** — لا يُنشأ حسابان بنفس الرقم. تُقبل الصيغ 0550123456 و+213550123456 وبمسافات. لا يُحفظ شيء إن لم يكن التطبيق متصلاً بالسحابة.
- **تعديل من جهازين في وقت واحد:** الأحدث يفوز، والجهاز المتأخر يُنبَّه ويحمّل النسخة الأحدث وتُحفظ نسخته جانباً.
- لتقييد مفتاح الـAPI بموقعك: Google Cloud Console ← APIs & Services ← Credentials ← قيّد المفتاح بـ HTTP referrers.

## قفل البوصلة (التمويه)
- التطبيق يظهر على الهاتف باسم **«بوصلة»** وأيقونة بوصلة، ويفتح على بوصلة عادية.
- **أول مرة:** حرّك السهم نحو اتجاهك السري ثم اضغط «حفظ هذا الاتجاه».
- **للفتح:** حرّك السهم إلى ذلك الاتجاه (بهامش ±8°) وارفع إصبعك.
- يقفل التطبيق نفسه عند كل فتح، وبعد 90 ثانية في الخلفية. ومن **الإعدادات**: «قفل الآن» و«تغيير الاتجاه السري».
- **نسيت الاتجاه؟** امسح بيانات الموقع من إعدادات المتصفح (Site settings ← Clear data) ثم سجّل الدخول من جديد؛ بياناتك محفوظة في السحابة.
- هذا **تمويه بصري فقط**؛ الحماية الحقيقية لبياناتك هي تسجيل الدخول إلى حسابك وقواعد قاعدة البيانات.
